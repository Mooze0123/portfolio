# New project checklist

Use the design system guide in [`../DESIGN-SYSTEM.md`](../DESIGN-SYSTEM.md) and the full content source in [`../PORTFOLIO-CONTENT.md`](../PORTFOLIO-CONTENT.md) when adding a case study.

Quick path:

1. Add the project’s writing, metadata and asset paths to `PORTFOLIO-CONTENT.md`.
2. Add one `.project-card` chapter to the homepage `index.html` with an `Open the story` link.
3. Add `projects/my-project/index.html` using the shared case-study frame and full process sections.
4. Keep the shared header, metadata rail, image frame, captions and navigation.
5. Run the local preview and check the mobile layout, page links and image proportions.
